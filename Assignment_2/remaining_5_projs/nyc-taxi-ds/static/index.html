The CRISP-DM 6-Phase Lifecycle for NYC Taxi DS

Cross-Industry Standard Process for Data Mining execution breakdown for this production pipeline.

Phase 1

Business Understanding

Formulate fleet routing optimization and transparent fare/ETA prediction for riders and dispatchers. Formulate primary optimization targets (trip_duration, fare_amount) and loss objectives (RMSE, RMSLE, MAE).

Phase 2

Data Understanding

Incorporate Kaggle NYC Taxi schema with latitude/longitude coordinates, timestamps, and passenger counts. Perform NYC geographic bounding box sanitization, temporal density profiling, and spatial hotspot clustering.

Phase 3

Data Preparation

Geospatial transformations including spherical Haversine, orthogonal Manhattan L1 distance, bearing degrees, airport radial detection (JFK, LGA, EWR), rush-hour & overnight flags, and standard feature scaling.

Phase 4

Modeling

Multi-model exploration across linear baselines (Linear Regression, Ridge L2) and non-linear ensembles (Random Forest, HistGradientBoosting) with K-Fold cross-validation.

Phase 5

Evaluation

Rigorously evaluate holdout partitions using RMSE, RMSLE, MAE, and R² scores. Perform residual error analysis and analyze global feature importances across models.

Phase 6

Deployment

Productionize inference via high-throughput FastAPI REST API with endpoints (/api/predict, /api/stats, /api/models, /api/routes) paired with this interactive Leaflet map interface.
